# Changelog

## 0.3.0

- Sign in with your StarMani account in every app; no key needed.
- Claude Code: `starmani@starmani-ai` now signs in. The key version is `starmani-api-key@starmani-ai`.
- MCP Registry entry no longer asks for a header.
- VS Code extension signs in unless you saved a key with "StarMani: Set API key".

## 0.2.1

- Moved to `starmani-ai/plugins`. Install with `claude plugin install starmani@starmani-ai`.

## 0.2.0

- Permanent address `https://api.starmani.com/mcp`.
- Claude Code plugin asks for the API key and stores it securely.
- Listed in the MCP Registry as `com.starmani/starmani`.
