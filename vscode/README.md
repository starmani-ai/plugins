# StarMani for VS Code

Adds StarMani's chart, timing, matching and calendar tools to VS Code's AI agent.

1. Create an API key at [starmani.com/developers/keys](https://starmani.com/developers/keys).
2. Run **StarMani: Connect with API Key** from the Command Palette and paste it. VS Code keeps it in its secret storage.
3. Enable the StarMani tools in your agent and ask: "Check my StarMani credit balance".

Paid tools use your StarMani credits; your AI model's usage is separate. **StarMani: Remove Saved API Key** removes the stored key; revoke it on StarMani to stop every copy.

No VS Code extension is needed for most people: the one-click install on [starmani.com/developers](https://starmani.com/developers) or a search for `@mcp StarMani` does the same.
