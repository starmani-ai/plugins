# Validation schemas

Agent Plugins 1.0.0 specification schemas, retrieved on 5 November 2026:

- `plugin.schema.json`: https://agent-plugins.org/schemas/1.0.0/plugin.schema.json
- `mcp.schema.json`: https://agent-plugins.org/schemas/1.0.0/mcp.schema.json

Stored unchanged for offline, reproducible validation. The schemas are Apache-2.0 software material; see `UPSTREAM-LICENSE.md` and `Apache-2.0.txt`, retained from https://github.com/agentplugins/agent-plugins-spec . OpenAI-specific manifest extension contents are outside the portable schema and require the publisher portal's checks as well.
